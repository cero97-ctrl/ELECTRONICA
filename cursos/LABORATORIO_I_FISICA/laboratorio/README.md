# Laboratorio del curso

Laboratorio físico de mesa. Cada grupo dispone de un juego de instrumentos y de una estación de análisis con Python para procesar sus propios datos.

Mesas con regla milimetrada, calibrador, tornillo micrométrico, balanza, probeta, cronómetro, termómetro digital, soportes, resortes, masas calibradas y cuerpos sólidos de distintos materiales y tamaños.

Este curso no usa contenedores: el laboratorio es físico y el material
de análisis se ejecuta en el equipo de cada grupo.

## Reglas

- No se energiza ningún equipo sin revisión previa del docente.
- Los líquidos se manipulan lejos de las balanzas y de las conexiones eléctricas.
- Cada instrumento se devuelve limpio, seco y en su estuche al terminar la sesión.
- El material roto se reporta de inmediato; ocultarlo agrava la sanción.
- Ningún dato se inventa ni se completa de memoria después de la sesión.
