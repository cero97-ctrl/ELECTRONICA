\subsection{Escanear el alcance antes y despues}

El mismo comando, la misma tasa y el mismo objetivo. La comparacion es puerto por puerto, no una impresion general.

\begin{lstlisting}[style=estiloCodigo]

nmap -sT -p 22,2222,8081,3000 --max-rate 20 127.0.0.1 \
  -oN semana_06/evidencia/antes.txt

  -oN semana_06/evidencia/despues.txt
diff -u semana_06/evidencia/antes.txt semana_06/evidencia/despues.txt \
  | tee semana_06/evidencia/diff.txt
\end{lstlisting}

\subsection{Probar si el puerto cerrado responde de otra forma}

Un puerto filtrado no es lo mismo que uno cerrado: se distingue con la salida de nmap y con una conexion directa cronometrada.

\begin{lstlisting}[style=estiloCodigo]
python3 - <<'PY' | tee semana_06/evidencia/cierre.txt
import socket, time
for puerto in (22, 2222):
    s = socket.socket(); s.settimeout(1.0)
    t = time.perf_counter()
    try:
        s.connect(('127.0.0.1', puerto)); estado = 'abierto'
    except socket.timeout:
        estado = 'filtrado'
    except ConnectionRefusedError:
        estado = 'cerrado'
    finally:
        s.close()
    print(puerto, estado, round(time.perf_counter() - t, 3), 's')
PY
\end{lstlisting}
