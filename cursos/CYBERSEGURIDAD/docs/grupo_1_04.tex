\needspace{5\baselineskip}
\section{\iconotexto{user-shield}{Tu rol en la práctica}}

Parte de su propia captura cruda y aplica el control equivalente: configuración, parche o regla de red. Repite el ataque para demostrar que falla y documenta el antes y el después.

\begin{itemize}[leftmargin=1.4em,itemsep=2pt,topsep=3pt]
  \item Leer su propia evidencia cruda y elegir el control que corta el ataque en el punto más barato.
  \item Aplicar el control y repetir el ataque para demostrar que ya no funciona.
  \item Documentar el antes y el después con los mismos comandos y la diferencia medida.
\end{itemize}

\needspace{5\baselineskip}
\section{\iconotexto{flag}{Qué aporta este rol al entregable}}

La mitigación aplicada, el comando de verificación y la comparación de resultados.

\needspace{5\baselineskip}
\section{\iconotexto{list-ol}{Ejemplo paso a paso}}

El rol Azul no se queda en el inventario: fija una linea base, aplica un control sobre un puerto concreto y repite la misma medicion. Lo que no se repite igual no demuestra nada.

\subsection{Fijar la linea base con la tasa autorizada}

La primera medicion se hace antes de tocar nada y con el limite de tasa del alcance. Se guarda la salida cruda y su hash.

\begin{lstlisting}[style=estiloCodigo]
mkdir -p semana_04/evidencia
nmap -sT -p 8081,3000,2222 --max-rate 20 127.0.0.1 \
  -oN semana_04/evidencia/antes.txt
sha256sum semana_04/evidencia/antes.txt > semana_04/evidencia/antes.sha256
\end{lstlisting}

\subsection{Aplicar un control sobre un puerto}

Se elige un control barato y reversible: denegar el puerto 2222 en el cortafuegos del host. Si el servicio debe seguir disponible para el grupo, se documenta la excepcion y no se aplica.

\begin{lstlisting}[style=estiloCodigo]
sudo nft add table inet filtro 2>/dev/null || true
sudo nft 'add chain inet filtro entrada { type filter hook input priority 0; }' 2>/dev/null || true
sudo nft add rule inet filtro entrada tcp dport 2222 drop
sudo nft list chain inet filtro entrada | tee semana_04/evidencia/regla.txt
\end{lstlisting}

\subsection{Repetir la medicion y diferenciar}

El mismo comando, sobre el mismo objetivo, con el control activo. El diff entre las dos salidas es la evidencia; si no cambia, el control no estaba donde se creia.

\begin{lstlisting}[style=estiloCodigo]
nmap -sT -p 8081,3000,2222 --max-rate 20 127.0.0.1 \
  -oN semana_04/evidencia/despues.txt
diff -u semana_04/evidencia/antes.txt semana_04/evidencia/despues.txt \
  | tee semana_04/evidencia/diff.txt
\end{lstlisting}

\subsection{Revertir el control y dejar el laboratorio como estaba}

Toda prueba tiene vuelta atras. Se elimina la regla, se verifica que el puerto responde otra vez y se anota el comando exacto que se uso.

\begin{lstlisting}[style=estiloCodigo]
sudo nft delete rule inet filtro entrada tcp dport 2222 drop 2>/dev/null || true
nmap -sT -p 2222 127.0.0.1 -oN semana_04/evidencia/revertido.txt
\end{lstlisting}
